========================================
  桌面宠物 · 小舞（MoePet）使用说明
========================================

【运行】
  双击「桌宠.exe」即可。免安装、绿色单文件。

【操作】
  · 鼠标左键按住拖动 —— 移动桌宠（拖动时有来回跑的姿势）
  · 左键点击角色   —— 轮流触发互动：跳跃 / 压扁回弹 / 左右抖动
  · 鼠标滚轮       —— 调整大小
  · 右键菜单：
      陪我聊聊天   —— 打开聊天窗口（可发文字 + 上传图片）
      摸摸头       —— 爱心特效 + 对话
      喂吃的       —— 掉落食物特效 + 对话
      让她走路     —— 在屏幕上来回散步（再点一下角色或菜单停止）
      让她睡觉     —— 躺下睡觉打呼 Zzz（点击角色唤醒）
      跟随鼠标     —— 追着光标跑
      调整大小     —— 滑块精确调大小
      跟随键盘鼠标 —— 桌宠同步反应你的输入活动（默认开启）：
                      打字时她会跟着快速摇摆 + 键盘 emoji + 偶尔吐槽；
                      空闲时她的视线会一直追着你的光标倾斜；
                      在别处点击鼠标她会轻微压扁回应
      开机自启     —— 勾选后开机自动启动桌宠（写入注册表 HKCU Run 键）
      置顶开关     —— 开启/取消窗口置顶
      退出程序     —— 关闭桌宠

【AI 聊天（agent）配置】
  桌宠目录下有一个 pet_config.json 文件，直接编辑它写入你的 API 即可，
  保存后重新打开聊天窗口生效（无需重启）。

  示例（DeepSeek 官方 API，纯文字聊天）：
  {
    "api_base": "https://api.deepseek.com",
    "api_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxx",
    "model": "deepseek-chat",
    "persona": "你是用户的桌面宠物，名叫小舞。说话简短俏皮（不超过25字），语气软萌，偶尔用颜文字。",
    "max_history": 10
  }

  字段说明：
    api_base    兼容 OpenAI 格式的接口地址（会自动补 /chat/completions，
                也支持带 /v1 或完整路径）
    api_key     你的 API Key（留空时聊天会使用内置卖萌回复）
    model       模型名称
    persona     桌宠人设（system 提示词），可自由改写性格
    max_history 携带的历史消息条数（不含 system）

  ★ 发图片给桌宠看（视觉对话）：
    聊天窗口点「🖼 图片」选择本地图片即可发送，图片会以 OpenAI 多模态
    格式（image_url + data URI，自动压缩到 640px 内）发给接口。
    注意：官方 DeepSeek（deepseek-chat）暂不支持图片输入，请换支持视觉
    的接口，例如智谱 glm-4v、通义 qwen-vl、OpenAI gpt-4o 等兼容端点，
    只需改 api_base / api_key / model 三项即可。

【常见问题】
  · 首次启动杀毒软件可能误报（PyInstaller 打包常见现象），添加信任即可。
  · 开机自启通过注册表指向当前 EXE 路径，移动 EXE 后需重新勾选一次。
  · 想彻底关闭：右键菜单选「退出程序」。
  · 配置文件被删也没关系，程序会自动重建默认模板。
  · 键盘/鼠标同步只统计按键次数和点击，不记录任何具体内容。
